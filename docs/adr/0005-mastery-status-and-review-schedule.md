# Статус освоения управляет допуском к интервальному повторению

Ручной статус освоения определяет, может ли карточка участвовать в интервальном повторении. Оценки ответов формируют её расписание и историю по постоянному UUID. Это позволяет временно убрать карточку из повторения и позже продолжить с накопленным прогрессом, даже если статус меняли непосредственно в Markdown.

## Последствия

Карточка со статусом «Изучена» или «Выучена» становится доступна сразу, если у неё ещё нет расписания. При статусе «Не изучена» или приостановке повторений карточка исключается из показа. После восстановления допуска действует сохранённый срок, а карточка с наступившим сроком доступна сразу. Приостановка действует во всех учебных разделах карточки.

Расписание и история относятся к карточке по UUID. При этом оценка в статистике относится к учебному разделу, из которого запущена сессия. Оценка интервального ответа сохраняет ручной статус освоения.
