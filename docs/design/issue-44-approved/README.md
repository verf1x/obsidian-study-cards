# Утверждённый макет Study Cards

Реализуемый вариант — **A · Практика** с доработками после просмотра. Зафиксирована ревизия `27b5e56b88f9e85e487808f7358dd69fa30e02df`. В макете можно подключить заметки прямо из списка, раскрыть предпросмотр отдельной заметки, найти завершённую проверку в «Истории» и вручную выбрать карточки с помощью поиска и галочек. [Исходники и запуск](https://github.com/verf1x/obsidian-study-cards/tree/27b5e56b88f9e85e487808f7358dd69fa30e02df/src/prototype/issue-44) · [Согласованное поведение](../00044-ux-follow-up.md)

## Повторить сценарии

Ревизия сохранена тегом `prototype/issue-44-approved`. Чтобы открыть её в отдельной папке, выполните из репозитория:

```powershell
git fetch origin tag prototype/issue-44-approved
git worktree add --detach ../study-cards-approved prototype/issue-44-approved
cd ../study-cards-approved
node src/prototype/issue-44/serve.mjs
```

Откройте [вариант A](http://127.0.0.1:4144/?variant=A&lang=ru&theme=dark). По умолчанию открывается раздел HTTP с готовым результатом. Через «Сценарий → Первый запуск» можно начать с пустого экрана и создать раздел из заметок. Перезагрузка сбрасывает учебные данные.

В нижней полосе макета находятся переключатели вариантов, сценария, темы и языка. Это инструменты для проверки макета. Настройки данных в плагине открываются через настройки Obsidian.
