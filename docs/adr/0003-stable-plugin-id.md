# Study Cards uses the permanent ID `study-cards`

[Русская версия](#russian)

The plugin will use **Study Cards** in the Community Directory and `study-cards` as its manifest ID and installation folder name. This ID identifies the plugin by its folder name. Changing it after publication would require users to reinstall the plugin. [Manifest](https://docs.obsidian.md/Reference/Manifest) · [Community Directory FAQ](https://docs.obsidian.md/community-directory/faq)

The `qcards` prefix in Markdown follows the source metadata format. The official directory showed no exact match for the name `Study Cards` or the ID `study-cards` on November 20, 2026. [Metadata format (#7)](https://github.com/verf1x/obsidian-study-cards/issues/7) · [Directory snapshot](https://github.com/obsidianmd/obsidian-releases/blob/bb4f4b010362f2919f51215c4bf27d178bd5e257/community-plugins.json) · [Decision in #12](https://github.com/verf1x/obsidian-study-cards/issues/12)

# Study Cards использует постоянный ID `study-cards`

Имя в Community Directory — **Study Cards**, а ID в manifest и имя установочной папки — `study-cards`. Этот ID позволяет узнать плагин по имени папки. После публикации смена ID потребует переустановки. [Manifest](https://docs.obsidian.md/Reference/Manifest) · [FAQ каталога](https://docs.obsidian.md/community-directory/faq)

Префикс `qcards` в Markdown следует формату метаданных из [#7](https://github.com/verf1x/obsidian-study-cards/issues/7). 20 ноября 2026 года в официальном каталоге не найдено точных совпадений для имени `Study Cards` и ID `study-cards`. [Снимок каталога](https://github.com/obsidianmd/obsidian-releases/blob/bb4f4b010362f2919f51215c4bf27d178bd5e257/community-plugins.json) · [Решение в #12](https://github.com/verf1x/obsidian-study-cards/issues/12)
