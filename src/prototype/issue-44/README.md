# Study Cards · прототип #44

```powershell
node src/prototype/issue-44/serve.mjs
```

Откройте [макет](http://127.0.0.1:4144/) во вкладке Orca. Нижние стрелки переключают варианты **A · Практика**, **B · Разделы**, **C · Карточки**. Вариант можно указать в ссылке, например `?variant=A`. Там же доступны тема, язык и сброс сценария.

- **Первый запуск.** Подключите сборник HTTP и отдельную заметку о TLS. Начните проверку, отметьте один промах, сохраните результат и попробуйте повторить ошибку.
- **Возврат к учёбе.** Запустите ручную проверку, вернитесь к практике и проверьте, какие галочки появились при новой настройке. Откройте другую карточку и сравните с «Начать с этой карточки». Удалите раздел и найдите его результат в «Истории».
- **Сбой хранения.** Откройте действия восстановления. В обычном сценарии инструменты снимков находятся в разворачиваемой части настроек.

Сессии и результаты существуют в памяти открытой страницы. Перезагрузка восстанавливает учебные данные. Настройки темы, языка и выбранный вариант читаются из адреса. Макет использует учебные заметки и имитацию хранения и восстановления. Он работает отдельно от Obsidian.
