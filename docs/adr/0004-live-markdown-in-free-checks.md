# Свободная проверка фиксирует состав и читает актуальный Markdown

При запуске свободной проверки сессия фиксирует состав и порядок карточек по UUID. Вопрос и эталон берутся из актуальной сохранённой версии Markdown. Это позволяет исправить текст прямо во время проверки и продолжить с той же позиции и с уже выставленными оценками.

## Последствия

При восстановлении сессии карточки заново находятся в источниках учебного раздела по сохранённым UUID. Недоступная карточка сохраняет место в сессии и выставленную оценку. Если тот же UUID снова доступен до завершения, пользователь может вернуться к карточке.
